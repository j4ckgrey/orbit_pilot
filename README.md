# Orbit Pilot

The phone companion for **Orbit AR** glasses, plus the Windows receiver for Orbit Cast.

## Downloads

Get the latest files from **[Releases](../../releases/latest)**:

| File | What it is |
|---|---|
| `OrbitPilot-v1.0.0.apk` | Android phone app: touchpad & keyboard for the glasses, casting both ways, remote shutter, brightness/volume, on-phone AI models, glasses diagnostics. Android 12 or newer. |
| `OrbitCastSetup-v1.0.0.exe` | Windows installer for Orbit Cast: receive the glasses' screen on a PC (Wi-Fi or USB). |
| `SHA256SUMS` | Checksums for the files above. |

## Install

- **Phone:** download the APK on the phone and open it (allow installing from your browser when Android asks). Then open Orbit Pilot and pair your glasses from the Glasses button.
- **PC:** run `OrbitCastSetup-v1.0.0.exe` and follow the installer.
