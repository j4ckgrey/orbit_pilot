# Orbit Pilot

The phone companion for **Orbit AR** glasses, plus Orbit Cast for Windows.

## Downloads

Get the latest files from **[Releases](../../releases/latest)**:

| File | What it is |
|---|---|
| `OrbitPilot-v1.0.0.apk` | Android phone app: touchpad & keyboard for the glasses, casting both ways, remote capture, brightness/volume, on-phone AI (translate, transcribe, 200-language translator), glasses diagnostics. 81 languages. Android 12 or newer. |
| `OrbitCastSetup-v1.0.0.exe` | Windows installer for Orbit Cast: mirror your PC on the glasses, or use them as a second monitor (Wi-Fi or USB). |
| `SHA256SUMS` | Checksums for the files above. |

## Install

- **Phone:** download the APK on the phone and open it (allow installing from your browser when Android asks). Then open Orbit Pilot and pair your glasses from the Glasses button.
- **PC:** run `OrbitCastSetup-v1.0.0.exe` and follow the installer.
